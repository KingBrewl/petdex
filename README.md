# PetDex

A collection log for hunters in World of Warcraft: Forever (interface `16001`). Find, tame and collect every beast, with rares and uniques as the headline collection.

## Development

The addon lives in `PetDex/`. Link it into the game so `/reload` picks up changes:

```powershell
New-Item -ItemType Junction `
  -Path "B:\Blizzard\World of Warcraft\_forever_\Interface\AddOns\PetDex" `
  -Target "$PWD\PetDex"
```

| File | Purpose |
|---|---|
| `Core.lua` | Namespace, event dispatch, saved variables, helpers |
| `Data/Beasts.lua` | Tameable beasts by NPC ID, **generated** from classic-db (see Data) |
| `Data/Overrides.lua` | Hand-made corrections on top of the generated data |
| `Data/Families.lua` | Each family's unique ability and Dash/Dive (from community guides) |
| `Data/FamilyData.lua` | Families, diets and icons, **generated** from the Forever client's CreatureFamily table |
| `Map.lua` | Spawn point to zone map position; pins it with the game's map pin to follow |
| `Collection.lua` | Seen/tamed records, beasts discovered in game, stats |
| `Tracking.lua` | Sightings, tame detection, active pet and stable backfill |
| `Skin.lua` | Native look and sound: game backdrops, bars, page buttons and UI sounds |
| `BeastStage.lua` | A beast's 3D model on a lit stage in its dex state (tamed, seen, silhouette), auto-framed |
| `DexWindow.lua` | The PetDex window (`/petdex`): tabs, header, and the Dex tab (families, looks, viewer) |
| `Views/Overview.lua` | Overview tab: totals, recent discoveries, progress per family |
| `Views/Hunt.lua` | Hunt tab: checklist of the beasts in your current zone, with map pins |
| `Views/Pets.lua` | My Pets tab: active pet and stable, with loyalty, happiness, training and abilities |
| `Views/Profile.lua` | Profile tab: hunter rank, points, rank track and achievements |
| `Points.lua` | Points (documenting and taming, by rarity), 40 hunter ranks, achievements |
| `Toast.lua` | Popup (with sound) when a beast is documented (first seen) or tamed |
| `MinimapButton.lua` | Minimap button that opens the dex |
| `Tooltip.lua` | Collection status on beast tooltips |
| `Probe.lua` | Debug probe: can the client read a unit's model (`/petdex probe`) |
| `ModelLab.lua` | Debug window: a beast in each dex state, plus turning, zoom, animations and a frame-rate test (`/petdex lab`) |
| `Slash.lua` | `/petdex` (`/pdex`) commands |

## Forever client notes

- Detect Forever by interface number (16000–19999), not `WOW_PROJECT_ID`.
- FrameXML lacks some old globals (`MouseIsOver`, `SetDesaturation`); use the widget methods.
- HD models; `SetCustomCamera(0)` portrait framing is ignored.

## Data

`Data/Beasts.lua` is generated by `tools/import-classic-db.mjs` (Node 18+) from the
[CMaNGOS classic-db](https://github.com/cmangos/classic-db) dump. It holds every tameable beast of
original Classic (1.12): family, levels, rank, display IDs (the dex's looks), attack speed and damage
school, spawn count and one spawn point, which the addon turns into a zone name in game. Beasts that
are new or changed in WoW Forever are learned in game as hunters meet them.

```sh
curl -LO https://raw.githubusercontent.com/cmangos/classic-db/master/Full_DB/ClassicDB_1_12_1_z2815.sql.gz
node tools/import-classic-db.mjs ClassicDB_1_12_1_z2815.sql.gz --stats   # counts per family
node tools/import-classic-db.mjs ClassicDB_1_12_1_z2815.sql.gz           # writes PetDex/Data/Beasts.lua
```

Don't edit `Beasts.lua` by hand; put corrections in `Data/Overrides.lua`.

`Data/FamilyData.lua` is generated by `tools/import-families.mjs` from the WoW Forever client's
CreatureFamily table: download it as CSV from [wago.tools](https://wago.tools/db2/CreatureFamily) for a
1.60.x build, then run `node tools/import-families.mjs CreatureFamily.1.60.x.csv`.

Which abilities a beast teaches isn't in the client data, so PetDex records it in game: right after a
tame, it reads the new pet's spellbook.
